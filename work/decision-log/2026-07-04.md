## 2. Native `<audio>` element instead of a custom player

**Decision:** The `AudioOverview` component wraps the browser-native
`<audio controls>` element rather than re-implementing a custom
play/pause/scrubber UI.

**Why:** The custom player is the highest-risk piece of the lost June 22
work (client component, keyboard scrubber, ARIA state management — all
hand-maintained). Native controls give keyboard access, media-session
integration, and screen-reader support for free, with zero client JS —
matching the project's CSS-first / lean rules. A download link covers
browsers without inline audio.

**Alternative considered:** Rebuilding the custom CSS-first player from the
Linear description. Skipped: more surface to break, no accessibility gain
over native controls, and the previous attempt proves it's easy to lose.

## 3. Honest labeling: "overview" vs "read-aloud" are different things

**Decision:** Frontmatter carries `audio_kind: overview | read_aloud`
(default `overview`). The component renders different bilingual labels for
each, and the overview label explicitly says it is an AI-made discussion
*about* the article, not the article word-for-word.

**Why:** The key SAY-372 finding — NotebookLM's two-host overview is an
engagement layer, not the accessibility read-aloud. Labeling an overview as
"listen to this article" would misrepresent AI-generated content to the
exact audience (elders, non-technical readers) the series is built to
protect. Panjabi label strings live in `LOCALE_META` next to the existing
`aiDraftBanner` (same pattern), flagged for sangat review.

## 4. R30 guard checks both directions

**Decision:** New lint rule R30 in `scripts/lint-content.mjs`:
(a) any `audio_url` must start with `/audio/`, use a supported extension
(.mp3/.m4a), and resolve to a real file under `public/` — ERROR;
(b) any file under `public/audio/` not referenced by a post — NOTICE
(catches orphaned uploads, per the follow-up suggested in today's review).
Rule ID R29 is left reserved: the open PR #2 introduces R29
(country-name consistency), so this branch takes R30 — which also matches
the rule ID the June 22 session used for the same guard.

**Why:** "Fail fast, fail loud" — the June failure was silent (work
sitting uncommitted). The rebuilt version makes every half-state loud:
mapping without file fails the build; file without mapping warns.
